# Legacy Documents

이 폴더는 Google Sheets MVP 시절의 문서를 보관하기 위한 위치다.

현재 Web v1.0 운영 기준은 다음 문서를 따른다.

- `docs/00_PROJECT_STATE_v1_0_WEB.md`
- `docs/01_WEB_ARCHITECTURE_SPEC.md`
- `docs/04_SONG_SCHEMA_JSON.md`
- `docs/05_GPT_SONG_OUTPUT_FORMAT.md`
- `docs/06_DATA_MAINTENANCE.md`

legacy 문서는 다음 용도로만 사용한다.

- Google Sheets MVP 구조 확인
- 과거 의사결정 추적
- taxonomy 원칙 참고
- 변환기/마이그레이션 히스토리 확인

주의:

> legacy 문서는 현재 source of truth가 아니다.
