# 쿠라's 노래책 — DESIGN_BRIEF

## 0. 문서 목적

이 문서는 쿠라's 노래책 Web v1.0 이후 유지해야 할 디자인 방향을 정리한다.

이 프로젝트는 일반적인 SaaS 대시보드가 아니다.  
단순한 데이터 테이블도 아니다.  
스트리머 팬페이지이면서, 방송 중 실제로 쓰기 좋은 노래 검색 페이지다.

---

## 1. 핵심 디자인 문장

> 말차색과 아이보리 바탕 위에, 핑크 해파리와 벚꽃 감성을 얹은 아기자기한 일본 팬사이트형 노래 검색 페이지.  
> 귀엽지만 유아틱하지 않고, 실용적이지만 SaaS 대시보드처럼 보이지 않는다.

---

## 2. 현재 디자인 기준

현재 v1.0은 다음 구조로 분리되어 있다.

```text
index.html = 감성/브랜딩/첫 진입 포털
search.html = 실전 검색 결과 페이지
```

따라서 두 페이지의 디자인 우선순위는 다르다.

### 포털

- 감성 우선
- 큰 검색창
- 핑크 해파리/말차/벚꽃 분위기
- 처음 들어온 사람에게 “검색하면 된다”를 알려줌

### 검색 결과 페이지

- 실사용성 우선
- 빠른 훑기
- 결과 카드 밀도
- 썸네일 클릭
- 가사/횟수/Pick
- 랜덤 추천

## 6. 에셋 방향

현재 사용 중:

- 핑크 해파리
- 말차/아이보리 배경
- 벚꽃/잎사귀 분위기
- hero background image

향후 추가 후보:

- favicon용 작은 핑크 해파리
- OG image / 공유 썸네일
- empty state용 해파리
- Pick collection용 카드더미 일러스트
- 랜덤 추천용 찻잔/음표 장식

주의:

- 특정 작품/캐릭터/아티스트의 공식 이미지, 로고, 캐릭터를 직접 에셋으로 쓰는 것은 피한다.
- 스트리머가 좋아하는 취향은 “추상적 감성”으로 반영한다.
  - 예: 카드게임 느낌 → 카드 프레임/희귀도/컬렉션 감성
  - 예: 마후마후/보카로 감성 → 하늘색/보라색 포인트, 리본, 음표, 중성적 보카로 무드
  - 예: 유희왕/마리크/라 → 직접 캐릭터가 아니라 황금 카드, 태양 날개, 고대 문양 느낌의 추상 장식

## 7. PC UI 원칙

PC 검색 페이지는 정보량을 어느 정도 허용한다.

정보 위계:

```text
1순위: 제목
2순위: 번역명
3순위: 가수 / 한국명 / 언어
4순위: songIntro
5순위: 장르 / 출처 / 작품명
6순위: 가사 / 횟수 / Pick
```

영상은 별도 버튼보다 썸네일 클릭을 기본으로 한다.

---

## 8. 모바일 UI 원칙

모바일은 정보 삭제가 핵심이다.

모바일에 유지할 정보:

- 제목
- 번역명
- 가수 · 언어
- 썸네일
- 핵심 장르/분위기
- 가사 버튼
- Pick

모바일에서 줄일 정보:

- 긴 출처
- 긴 비고
- 너무 많은 칩
- 상세 상황/대상/감정
- 복잡한 fixed search

모바일은 v1.0에서 rough beta이고, v1.2에서 별도 개선한다.

## 10. 디자인 우선순위

1. 검색이 빠르게 된다.
2. 결과를 빠르게 훑을 수 있다.
3. 귀엽고 쿠라맛챠스럽다.
4. 방송 중 사용하기 어렵지 않다.
5. 모바일에서 크게 깨지지 않는다.
6. 장기적으로 관리 가능하다.
