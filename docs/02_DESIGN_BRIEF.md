# 쿠라's 노래책 — DESIGN_BRIEF

## 0. 문서 목적

이 문서는 쿠라's 노래책 GitHub Pages 이전 시 유지해야 할 디자인 방향을 정리한다.

이 프로젝트는 일반적인 SaaS 대시보드가 아니다.  
단순한 데이터 테이블도 아니다.  
스트리머 팬페이지이면서 방송 중 실제로 쓰기 좋은 노래 검색 페이지다.

## 1. 핵심 디자인 문장

> 말차색과 아이보리 바탕 위에, 핑크 해파리와 벚꽃 감성을 얹은 아기자기한 일본 팬사이트형 노래 검색 페이지.  
> 귀엽지만 유아틱하지 않고, 실용적이지만 SaaS 대시보드처럼 보이지 않는다.

## 2. 무드 키워드

우선 키워드:

- 말차
- 아이보리
- 연핑크
- 핑크 해파리
- 벚꽃
- 잎사귀
- 일본 개인 팬사이트
- 애니 굿즈샵
- 카드 컬렉션
- 방송용 검색 페이지
- 부드러운 음악 검색 UI
- 아기자기하지만 정돈됨

보조 키워드:

- 니코동/보카로 감성 약간
- 유희왕 카드 감성 약간
- 2000년대 개인 홈페이지 감성 약간
- 하지만 현대 웹처럼 읽기 쉬워야 함

| Main matcha | 진한 말차 | `#6F8F5E` |

| Background ivory | 따뜻한 아이보리 | `#FCFCF8` |

색상 사용 원칙:

- 배경은 밝고 따뜻하게.
- 말차색은 구조를 잡는 색.
- 연핑크는 포인트로만.
- 텍스트는 검정 대신 녹갈색 계열.
- 과한 채도는 피한다.

## 5. 레이아웃 참고 방향

### 5.1 메인 도입부

Google 검색창 같은 단순한 도입부를 참고할 수 있다.

구조:

```text
로고/타이틀
간단한 설명
큰 검색창
추천 필터/검색어
오늘의 랜덤 추천
```

목표:

- 처음 들어온 사람이 바로 검색할 수 있어야 한다.
- 사용법이 길면 안 된다.
- 검색창이 중심이어야 한다.

### 5.2 검색 결과

Melon 같은 음악 검색 결과 구조를 참고할 수 있다.

참고할 점:

- 곡명 중심
- 가수/앨범/메타 정보의 명확한 위계
- 오른쪽 또는 별도 영역에 인기 검색어/추천 영역
- 리스트형 결과의 빠른 훑기

하지만 Melon을 그대로 복제하지 않는다.  
최종 결과는 쿠라 노래책 테마로 재해석한다.

## 6. PC UI 원칙

PC는 정보량을 어느 정도 허용한다.

PC 결과 카드/리스트에 들어갈 정보:

- 제목
- 번역명
- 가수
- 한국명
- 언어
- 장르
- 주제
- 출처
- 영상 버튼
- 가사 버튼
- 부른 횟수
- Pick

PC 정보 위계:

```text
1순위: 제목
2순위: 번역명
3순위: 가수 / 한국명 / 언어
4순위: 장르 / 주제
5순위: 출처
6순위: 영상 / 가사 / 횟수 / Pick
```

디자인 원칙:

- 리스트형 카드가 좋다.
- DB 표처럼 보이면 안 된다.
- 행 간격을 충분히 둔다.
- 세로선은 최소화한다.
- 카드 테두리는 아주 약하게.
- 그림자는 부드럽고 과하지 않게.
- 버튼은 작지만 명확해야 한다.

## 7. 모바일 UI 원칙

모바일은 정보 삭제가 핵심이다.

모바일에 유지할 정보:

- Pick
- 제목
- 번역명
- 가수 · 언어
- 장르
- 영상 버튼
- 가사 버튼

모바일에서 줄일 정보:

- 긴 출처
- 긴 비고
- 부른 횟수
- 상세 상황/대상/감정
- 너무 많은 필터

모바일 원칙:

- 한 곡 = 한 카드
- 좌우 스크롤 금지
- 버튼은 손가락으로 누르기 쉬워야 한다.
- 필터는 접거나 칩 형태로 둔다.
- 화면이 예뻐도 검색이 느리면 실패다.

## 8. 카드 감성

이 프로젝트의 “카드”는 일반 SaaS card가 아니라, 약간의 컬렉션 감성을 가진 음악 카드다.

참고 감성:

- 애니 굿즈샵의 상품 카드
- 유희왕 카드의 “수집/선택” 감성 약간
- 노래방 책의 빠른 검색성
- 일본 개인 팬사이트의 부드러운 장식

하지만 실제 UI는 정돈되어야 한다.

카드가 가져야 하는 느낌:

```text
찾기 쉽다
누르기 쉽다
귀엽다
정보가 정돈되어 있다
```

카드가 가지면 안 되는 느낌:

```text
복잡하다
유아틱하다
게임 UI처럼 과하다
광고 배너 같다
```

## 9. 장식 사용 원칙

허용 장식:

- 핑크 해파리
- 작은 벚꽃
- 잎사귀
- 말차 컵/찻잔
- 부드러운 거품/반짝임
- 얇은 라인 장식

주의:

- 장식이 검색을 방해하면 안 된다.
- 배경 일러스트는 텍스트 대비를 해치면 안 된다.
- 모바일에서는 장식을 줄인다.
- 장식은 기능 영역보다 바깥에 둔다.

## 10. 폰트 원칙

권장:

- 시스템 sans-serif 우선
- 일본어/한국어 가독성 우선
- 제목은 둥글고 부드러운 인상
- 본문은 읽기 쉬워야 한다

피해야 할 것:

- 지나치게 장식적인 폰트
- 일본어가 깨지는 웹폰트
- 너무 얇은 글씨
- 모바일에서 작게 보이는 폰트

## 11. 버튼 원칙

주요 버튼:

- `▶ 영상`
- `📄 가사`
- `📄 가사 준비 중`
- `🎲 랜덤`
- `필터 초기화`
- `상세 필터`

버튼 기준:

- 버튼은 명확해야 한다.
- 비활성 버튼은 눌리지 않는다는 것이 보여야 한다.
- 영상 버튼과 가사 버튼은 같은 위계로 둔다.
- Pick은 버튼이 아니라 상태 표시다.

## 12. 성공 기준

디자인 성공 기준:

- 첫 화면에서 검색창이 바로 보인다.
- 팬페이지 감성은 있지만 기능을 방해하지 않는다.
- 모바일에서 결과 카드가 읽기 쉽다.
- PC에서 많은 곡을 빠르게 훑을 수 있다.
- Google Sheets 느낌이 사라진다.
- 사용자가 “공식 검색 페이지 같다”고 느낀다.
- 하지만 너무 기업형 서비스처럼 보이지 않는다.
